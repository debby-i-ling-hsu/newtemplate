## 1. 產品概述

- **一句話定位**：到府除蟎 / 洗冷氣服務平台，串接「客戶 / 業務 / 行政」三方協作。
- **核心閉環**：`客戶下單 → 系統自動派工 → 業務完工回報 → 客戶評分 → 行政計酬`。
- **主要角色**：
  - **客戶**：手機自助註冊，預約免費體驗 / 套組 / 洗冷氣、查詢預約、查看服務紀錄與評分、收補償服務。
  - **業務（師傅）**：由行政開通帳號，查今日派工、看派工詳情、完工回報、棄單、查個人中心。
  - **行政**：由行政開通帳號，於 Django Admin 後台管理服務型錄、預約、完工計酬、客戶、業務、班表、操作歷程。
- **範圍邊界**：不接真實金流、不發真實簡訊；商業規則（派工演算、計酬級距）目前為模擬，待案主確認細節後再深化。

## 3. 資訊架構 / 導覽

- **Web（同一個 SPA，依角色切換）**
  - 客戶：首頁 `/`、預約 `/book/:type`、我的預約 `/bookings`、服務紀錄 `/history`、個人 `/profile`。
  - 業務：派工 `/staff`(`/`)、派工詳情 `/booking/:id`、完工回報 `/completion/:id`、班表 `/schedule`、個人 `/me`。
  - 行政：自動導向 Django Admin `/admin/`。
- **Mobile（Expo，依角色切換）**
  - 客戶底部 tab：首頁 / 我的預約 / 服務紀錄 / 個人；下單與評分為覆蓋畫面。
  - 業務底部 tab：派工 / 個人；派工詳情、完工回報為覆蓋畫面。
- **後台（Django Admin + unfold）**：服務型錄、預約與完工、派工與排班、帳號與權限四個分群。

## 4. 功能清單（重點）

### 4.1 手機 OTP 註冊 / 登入　✅　⭐
- **流程**：輸入手機 → 收驗證碼（模擬固定 `000000`）→ 驗證。手機不存在則自助建立為**客戶**；業務 / 行政帳號由行政在後台建立並指派角色。
- **資料模型**：`accounts.User`（`phone` unique、`role`：customer/technician/admin）。
- **API**：`POST /api/v1/accounts/otp/request/`、`POST /api/v1/accounts/otp/verify/`（回 JWT + user）、`GET/PATCH /api/v1/accounts/me/`、`POST /accounts/token/refresh/`。
- **權限**：登入後 `/me.role` 決定進客戶 App / 業務 App / 後台。

### 4.2 客戶下單（demo / package / ac）　✅　⭐
- **目的**：客戶選服務、選時段，系統自動指派服務區涵蓋其行政區的在線業務。
- **資料模型**：`bookings.Booking`（customer/staff/service_type/date/slot/status/地址快照/ac 欄位）。
- **規則**：套組服務成立時扣一次 `pkg_remaining`；金額為試算、未含金流；派工為模擬演算法。
- **API**：`GET/POST /api/v1/bookings/bookings/`、`POST .../{id}/cancel/`。
- **介面**：Web `features/bookings/`、Mobile `features/bookings/`。

### 4.3 業務完工回報與計酬　✅　⭐
- **流程**：業務在派工詳情提交完工 → 確認服務項目、客戶簽名 → demo 無車馬費，其餘以 `catalog.PayrollSetting.travel_fee` 計酬（模擬，不撥款）。
- **併發**：完工 / 棄單於 `services.py` 用 `transaction.atomic` + `select_for_update`，且 idempotent（重送不重複建立）。
- **API**：`GET /api/v1/bookings/dispatch/`、`POST .../{id}/complete/`、`POST .../{id}/abandon/`。

### 4.4 棄單與補償　✅　⭐
- 業務棄單記錄原因，建立 `bookings.Compensation`（客戶獲一次免費補服務），模擬推播補單。客戶於個人頁可見補償。

### 4.5 客戶評分　✅　⭐
- 完工後客戶評 1–5 星，系統重算該業務 `StaffProfile.rating`。API：`POST /api/v1/bookings/completions/{id}/rate/`。

### 4.6 業務班表　✅　⭐
- 業務提交次月各日各時段是否開放接單。API：`GET/PUT /api/v1/staffing/schedule/?month=`。（Web 已具備；Mobile 後續補。）

### 4.7 行政後台（Django Admin）　✅　⭐
- 服務型錄：`Service` / `ServicePackage` / `Promotion` / `PayrollSetting`（單例車馬費）。
- 預約與完工：`Booking`（改派、手動代建）、`Completion`（**匯出獎金 CSV**、標記已匯出）、`Compensation`、`OperationLog`（唯讀）。
- 帳號：`CustomerProfile`（套組次數、代建）、`StaffProfile`（狀態 online/banned/disabled、服務區）。
- 派工排班：`ServiceArea`、`StaffSchedule`。
